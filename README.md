# -Student-Data-Management-Using-Linked-List-Data-Structure

Developed a modular, menu-driven Student Record Management System in C using the Singly Linked List data structure. The application efficiently manages student records through dynamic memory allocation, file handling, searching, sorting, modification, and deletion operations.

**Key Features:**
Automatic Roll Number Assignment:** Assigns the smallest available positive integer as a unique roll number.
Record Management: Supports adding, displaying, searching, modifying, and deleting student records.
Flexible Search: Search and modify records using Roll Number, Name, or Percentage.
Sorting: Organizes records alphabetically by Name or in descending order of Percentage.
Linked List Operations: Implements in-place list reversal and deletion of all records.
Data Persistence: Uses binary file handling to save and retrieve student records from `student.dat`.
Memory Management: Uses `malloc()` and `free()` for dynamic memory allocation and proper deallocation.

Technologies Used: C Programming, Singly Linked Lists, Pointers, Structures, Dynamic Memory Allocation, Binary File Handling, Searching, Sorting, GCC, and Makefile.

Compilation & Execution: Uses GCC and Makefile to compile and execute the application.
